# 社区武学传习风控平台

本服务用于教练凭据、参与者限制和课程安全放行。仓库提供可启动的健康检查、SQLite 迁移入口和最小测试，领域功能将在这些约定上持续建设。

## 领域资料

核心记录包括：认证机构、教练凭据、合作单位、课程、参与者声明、监护同意、紧急访问。

排课确认时冻结资格判定；凭据撤销阻止新课并提示旧课；敏感健康信息按职责披露；紧急访问必须限时并复核。

## 本地命令

执行 ./scripts/migrate 可重复应用数据库迁移；执行 ./scripts/test 运行自动化测试；执行 ./scripts/start 启动 HTTP 服务。数据库默认写入 data/martial_clearance.sqlite3，也可通过 DATABASE_PATH 指定其他路径；监听地址由 HOST 和 PORT 配置。

Docker 镜像构建后使用相同的迁移与启动入口，运行期间不需要外部数据库、缓存或消息服务。
